# Changelog

## [2026.10.0] - 2026-10-20

### Added

- Initial Kotlin and Jetpack Compose Android project.
- Gradle version catalog, wrapper, and release signing configuration.
- CI workflow for formatting, lint, tests, and debug builds.
- Release workflow that publishes a signed APK to GitHub Releases.
- Docusaurus documentation and GitHub Pages deployment.
- Repository templates, funding metadata, and contribution guidelines.
