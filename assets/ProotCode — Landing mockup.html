Thirteen
blocks.

Roadmap features. The project is at initial scaffold; runtime is being built in the open.

01

Distro selector

Pick Debian or Ubuntu for each new environment.

02

Rootless Linux

proot-based install. No root access, ever.

03

Non-root user

A regular user with a persistent home directory.

04

Storage bridge

Bind Android folders like Downloads into your Linux home.

05

Package manager

Run apt commands straight from the app interface.

06

Essential presets

Git, build-essential, curl and OpenCode pre-installed.

07

Tool selection

Choose dev tools by category before installing.

08

Multi terminals

Several sessions open on the same distribution.

09

Code Server

VS Code in the browser, on your local network, with mobile CSS.

10

Mouse support

Pointer integration for proot and the Linux environment.

11

Resource controls

Monitor and limit battery and CPU usage.

12

Install progress

Follow every step of the distribution setup.

13

Backups

Export and restore projects and configuration.

Everything runs on your device.

steps.

1

Install

2

Deploy

Choose Debian or Ubuntu, pick your tools, watch the setup progress.

3

Build

Open terminals, or launch Code Server and code from the browser.
